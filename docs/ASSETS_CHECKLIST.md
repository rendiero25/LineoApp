# Store Assets Checklist — Lineo

Required graphic assets for the Google Play Store listing.

## 1. App Icon
- **Specifications:** 512 x 512 px, 32-bit PNG (with alpha).
- **Adaptive Icon:** Ensure foreground and background vectors are correctly implemented in the app (currently using default Android bot).
- **Design Note:** Should be clean and reflect the "line-based" nature of Lineo.

## 2. Feature Graphic
- **Specifications:** 1024 x 500 px, JPEG or 24-bit PNG (no alpha).
- **Purpose:** Shown at the top of the store listing.

## 3. Screenshots (Phone)
- **Minimum:** 2 screenshots.
- **Specifications:** 16:9 or 9:16 aspect ratio. Each side between 320 px and 3840 px.
- **Key Screens to capture:**
    1. **Notepad Mode:** Showing a calculation with variables and line references.
    2. **Scientific Module:** Showing complex functions (trig, log).
    3. **Unit Converter:** Showing a conversion between units.
    4. **History Tape:** Showing previous results.

## 4. Screenshots (Tablet / Foldable)
- **Tablet:** At least 1 screenshot for 7-inch and 1 for 10-inch tablets.
- **Foldable:** Capture the adaptive layout (two-pane if implemented).

## 5. Metadata
- **Title:** `Lineo: Notepad Calculator` (25 characters).
- **Short Description:** `A notepad-based calculator for free-form multi-line documents.` (80 characters).
- **Full Description:** Describe the unique "Notepad mode" where lines can reference each other, and the integrated modules (Scientific, Converter).
